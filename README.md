## What it does

`main.py` (pure Python standard library, no dependencies) writes a single
one-line 1-star review, in the voice of a houseplant reviewing its human
owner, to `/output/entry.txt`. The line is 166 characters — under the
280-character cap — and deterministic, so both graded runs produce the
same text.

> One star. She waters the plastic succulent next to me twice a week and
> calls me 'low-maintenance' while I die of thirst one pot over. The
> plastic one is outliving me.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
